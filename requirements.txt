# ============================================
# Установка Octotraher из ПРИВАТНОГО Git репозитория
# ============================================
#
# ВАРИАНТ 1: Через HTTPS с Personal Access Token (рекомендуется)
# Замените YOUR_TOKEN на ваш GitHub Personal Access Token
# Замените YOUR_USERNAME на ваш GitHub username
# Замените main на нужную ветку (если не main)
#
git+https://YOUR_TOKEN@github.com/YOUR_USERNAME/octotraher.git@main
#
# Пример реальной строки (скопируйте и замените значения):
# git+https://ghp_xxxxxxxxxxxxxxxxxxxx@github.com/username/octotraher.git@main
#
# ============================================
#
# ВАРИАНТ 2: Через SSH (если настроен SSH ключ)
# git+ssh://git@github.com/YOUR_USERNAME/octotraher.git@main
#
# ============================================
#
# Дополнительные опции:
# - Конкретная версия/тег: @v0.1.0 вместо @main
# - Конкретный коммит: @abc123def456
# - Конкретная ветка: @develop
#
# ============================================
# 
# ИНСТРУКЦИЯ ДЛЯ КОПИРОВАНИЯ В ДРУГОЙ РЕПОЗИТОРИЙ:
# 
# 1. Раскомментируйте нужный вариант (уберите # в начале строки)
# 2. Замените YOUR_TOKEN, YOUR_USERNAME и ветку на реальные значения
# 3. Скопируйте строку с git+https://... или git+ssh://...
# 4. Вставьте в requirements.txt другого проекта
#
# ============================================
