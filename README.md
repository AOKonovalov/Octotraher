# Octotraher
Octotraher — это скрейпер для социальных сетей (SNS). Он собирает данные о профилях пользователей, хештегах или поисковых запросах и возвращает найденные элементы, например, соответствующие посты.

Поддерживаются следующие сервисы:

* Facebook: профили пользователей, группы и сообщества (также известные как visitor posts)
* Instagram: профили пользователей, хештеги и локации
* Mastodon: профили пользователей и туты (одиночные или в треде)
* Reddit: пользователи, подреддиты и поиск (через Pushshift)
* Telegram: каналы
* Twitter: пользователи, профили пользователей, хештеги, поиск, твиты (одиночные или в треде), посты из списков и тренды
* VKontakte: профили пользователей
* Weibo (Sina Weibo): профили пользователей

## Требования
Octotraher требует Python 3.8 или выше. Зависимости Python-пакетов устанавливаются автоматически при установке octotraher.

Обратите внимание, что одна из зависимостей, lxml, также требует установки libxml2 и libxslt.

## Установка

### Установка из локальной директории

Для установки Octotraher из текущей директории:

```bash
pip install .
```

Или в режиме разработки (editable install):

```bash
pip install -e .
```

### Установка из Git репозитория

Если вы хотите установить напрямую из Git репозитория:

```bash
pip install git+https://github.com/AOKonovalov/Octotraher.git
```

Замените `yourusername` на ваш реальный GitHub username.

### Установка из исходного дистрибутива

1. Создайте исходный дистрибутив:
```bash
python setup.py sdist
```

2. Установите из созданного дистрибутива:
```bash
pip install dist/octotraher-0.1.0.tar.gz
```

## Использование
### CLI
Общий синтаксис CLI Octotraher:

    octotraher [GLOBAL-OPTIONS] SCRAPER-NAME [SCRAPER-OPTIONS] [SCRAPER-ARGUMENTS...]

`octotraher --help` и `octotraher SCRAPER-NAME --help` предоставляют детали об опциях и аргументах. `octotraher --help` также выводит список всех доступных скрейперов.

По умолчанию CLI выводит URL каждого результата.

Некоторые примечательные глобальные опции:

* `--jsonl` для получения вывода в формате JSONL. Это включает всю информацию, извлеченную octotraher (например, содержимое сообщения, дата и время, изображения; детали различаются в зависимости от скрейпера).
* `--max-results NUMBER` для возврата только первых `NUMBER` результатов.
* `--with-entity` для получения информации о сущности, которая скрейпится, например, пользователь или канал. Это поддерживается не всеми скрейперами. (Вы можете использовать это вместе с `--max-results 0` для получения только информации о сущности.)

#### Примеры
Собрать все твиты от Jason Scott (@textfiles):

    octotraher twitter-user textfiles

Обычно полезно перенаправить вывод в файл для дальнейшей обработки, например, в bash используя имя файла `twitter-@textfiles`:

```bash
octotraher twitter-user textfiles >twitter-@textfiles
```

Чтобы получить последние 100 твитов с хештегом #archiveteam:

    octotraher --max-results 100 twitter-hashtag archiveteam

### Библиотека
Также можно использовать Octotraher как библиотеку в Python:

```python
import octotraher.modules.telegram as telegram

# Пример использования
scraper = telegram.TelegramChannelScraper('channelname')
for item in scraper.get_items():
    print(item)
```

## Публикация на PyPI (Опционально)

Если вы хотите опубликовать Octotraher на PyPI, чтобы другие могли установить его через `pip install octotraher`:

1. Создайте аккаунты на [PyPI](https://pypi.org) и [Test PyPI](https://test.pypi.org)
2. Установите инструменты сборки:
```bash
pip install build twine
```

3. Соберите пакет:
```bash
python -m build
```

4. Сначала загрузите на Test PyPI (для тестирования):
```bash
python -m twine upload --repository testpypi dist/*
```

5. Если всё работает, загрузите на PyPI:
```bash
python -m twine upload dist/*
```

## Сообщение об ошибках
Если вы обнаружили ошибку в Octotraher, пожалуйста, сообщите о ней в трекере проблем проекта. По возможности запустите octotraher с `-vv` и `--dump-locals` и приложите вывод логов, а также файлы дампов, упомянутые в логе, к сообщению об ошибке. Обратите внимание, что файлы могут содержать конфиденциальную информацию в некоторых случаях и могут потенциально использоваться для вашей идентификации (например, если сервис включает ваш IP-адрес в ответ). Если вы предпочитаете организовать передачу файлов приватно, просто упомяните об этом в сообщении об ошибке.
